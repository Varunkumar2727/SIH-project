# GeoCadastral AI

**GeoCadastral AI** is an AI-assisted cadastral mapping & land feature segmentation prototype built for **SIH 2026**. It takes aerial or satellite images and uses computer vision algorithms to identify visible land features (Buildings, Roads, Vegetation, Open Land), synthesize AI-proposed parcel boundaries, and export valid GeoJSON polygons.

> [!IMPORTANT]
> **SIH Prototype Disclaimer**: Outputs generated by this application are AI-proposed boundaries for demonstration and preliminary analysis only. They are **not legally authoritative cadastral records** and require verification by an authorized surveyor or government authority.

## 4. Technical Architecture: Real Computer Vision vs. AI Segmentation

### Currently Implemented (Prototype Computer Vision)
- **Vegetation Segmentation**: HSV color space green hue filtering (`H: 25-90`), morphological opening/closing, and OpenCV contour simplification.
- **Road Infrastructure**: Low-saturation asphalt HSV filtering combined with directional rectangular morphological kernels (`17x3` and `3x17`) to isolate linear transport pathways.
- **Building Structures**: Roof color contrast, adaptive thresholding, shape aspect ratio, extent analysis (`area / (w * h)`), and rectangular contour fitting.
- **AI-Proposed Parcel Boundaries**: Synthesizes property envelopes by buffering building boundaries and open land polygons, tagging each feature with metadata:
  ```json
  {
    "parcel_id": "AI-P001",
    "type": "proposed_parcel",
    "status": "requires_verification"
  }
  ```

### Pluggable Interface
The detection engine is isolated inside `backend/services/detection.py` under the function `analyze_image(image_path)`. Replacing the computer vision algorithm with a PyTorch/ONNX deep neural network requires zero frontend changes.

## 5. Recommended Pretrained Models & Datasets for Next Version

For the next production version of **GeoCadastral AI**, we recommend replacing the prototype computer vision engine with:

1. **Segment Anything Model 2 (SAM 2)** by Meta AI:
   - Zero-shot spatial boundary segmentation for high-resolution satellite imagery.
2. **SegFormer (b2/b5)** trained on **Inria Aerial Image Labeling Dataset**:
   - Deep transformer model specialized in urban roof extraction and building footprint polygonization.
3. **DeepGlobe Land Cover Classification Dataset & ResNet-UNet**:
   - 7-class satellite land cover segmentation (urban, agriculture, forest, water, barren, road).
4. **SpaceNet 7 Multi-Temporal Urban Development Dataset**:
   - Ideal for tracking building construction and automated cadastral parcel boundary updates over time.
