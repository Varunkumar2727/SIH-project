# GeoCadastral AI — AI-Assisted Cadastral Mapping & Land Intelligence System

**GeoCadastral AI** is a production-grade geospatial intelligence and cadastral mapping platform designed for land administration, revenue departments, survey organizations, and enterprise GIS operations. It combines computer vision, topological parcel intelligence, temporal change monitoring, human-in-the-loop survey verification, and enterprise GIS interoperability.

> [!IMPORTANT]
> **STATUTORY NOTICE & SURVEY POSITIONING:**
> Outputs generated by this application are AI-assisted delineations and decision-support indicators. They do **not** independently establish legal title, deed ownership, or replace authoritative boundary settlements. All proposed boundaries and discrepancy cues require survey verification by a competent authority.

---

## 1. System Architecture & Parts Overview

* **Part 1 — Geospatial Foundation**: GeoTIFF reader, Projected/Geographic CRS, affine transforms, WGS84 coordinates.
* **Part 2 — Ground Control Points (GCP)**: 2D affine least-squares estimation, residual errors, and RMSE accuracy reporting.
* **Part 3 — Real AI Feature Detection**: Tiled inference (512x512 with 15% overlap) to prevent boundary artifacts; ONNX Runtime with CUDA 13.1 detection and CPU fallback.
* **Part 4 — Access Path Intelligence & Frontage**: Morphological skeletonization, topological `networkx.Graph`, and physical parcel access evaluation.
* **Part 5 — Parcel Intelligence & Cadastral Comparison**: Deterministic parcel hash IDs (`AI-P-XXXXXXXX`), topological validation, and authoritative survey IoU comparisons.
* **Part 6 — Temporal Change Detection**: Multi-temporal change classification (`NEW_CONSTRUCTION`, `MODIFIED_FOOTPRINT`, `STRUCTURE_REMOVAL`) with chronological validation.
* **Part 7 — Survey Officer Verification Workflow**: Human-in-the-loop review queue, append-only immutable audit log, and field verification task dispatch.
* **Part 8 — Government-Ready Reporting & Deliverables**: ReportLab PDF dossier generation, attribute CSV exports, and offline survey ZIP bundles.
* **Part 9 — Advanced Land Analytics**: Explainable 0–100 Development Readiness & Discrepancy Risk scoring, and spatial hotspot density clustering.
* **Part 10 — Multi-Tenant Enterprise Platform**: SQLite with WAL mode & foreign keys, 6 RBAC roles, and tenant data isolation.
* **Part 11 — Production Infrastructure**: Asynchronous job queue (`JobManager`) with dedicated CPU and GPU worker queues.
* **Part 12 — Indian AI Training & Dataset Pipeline**: Indian aerial datasets (urban, rural, agricultural, coastal), leakage-free spatial splitting, transfer learning fine-tuning, and model registry.
* **Part 13 — Enterprise GIS Integrations**: WMS, WMTS, WFS, GeoPackage, and Shapefile connectors with strict SSRF defense.
* **Part 14 — SaaS API Platform**: Public `/api/v1` REST API, scoped API keys with SHA-256 hashed secrets, idempotency keys, and measured usage tracking.
* **Part 15 — Production Launch & Security Hardening**: Path traversal defense, secret scanning, disaster recovery backup/restore testing, and 45 automated unit tests.

## 2. Installation & Quickstart

### Prerequisites
* Windows 10/11 or Linux
* Python 3.10+ (tested on Python 3.14)
* Node.js v18+ and `npm`
* NVIDIA GPU with CUDA support (e.g. RTX 3050)

### Setup Virtual Environment & Dependencies
```powershell
# In repository root
.\venv\Scripts\activate
pip install -r requirements.txt
```

### Running Tests
Execute the comprehensive automated test suite (45 unit tests):
```powershell
.\venv\Scripts\python.exe -m unittest discover -s backend/tests
```

### Starting the Backend Server
```powershell
.\venv\Scripts\python.exe backend/main.py
```
* API Server: `http://localhost:8000`
* Swagger Docs: `http://localhost:8000/docs`
* Public v1 API: `http://localhost:8000/api/v1`

### Starting the Frontend Dashboard
```powershell
cd frontend
npm run dev
```
* Dashboard URL: `http://localhost:5173`
